# SIGACE - API

API do Sistema de Gestão de Atendimento para Cartório Eleitoral.

## Tecnologias

- Node.js
- Express
- SQLite
- CORS

## Funcionalidades da API

- Cadastro de eleitores
- Consulta de eleitores
- Registro de atendimentos
- Consulta do histórico de atendimentos
- Atualização do status do atendimento
- Consulta de atendimento por ID
- Cadastro de servidores
- Indicadores do dashboard

## Execução

O projeto utiliza o arquivo `server.js` como ponto de entrada da API.

A porta utilizada é:

3000
